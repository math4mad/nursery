PREREG_N01 — 缺-复探针（客体恒常假说机 · Nursery own 案第一号）

立案日 2026-09-28（主人面谕「get a first experiment for nursery project」； 园笔点菜骨架 01 列·客体恒常性，8–12m 窗）。判据先冻后用，本册先于开火冻结， 发射后一字不动。CPU 舱，numpy 标量动力学，无 GPU 席位之争；与 PB24 同族（假说机，非语料实证）。

问的题（一题两刀）

  1. 存活刀：输入缺席（遮蔽）Δ 拍后重现，概念的锚点是「深藏待唤」还是「灰飞须重学」？
  2. 错置刀：皮亚杰 A-not-B 错（藏 A 于 A 处多次后改藏于 B，婴儿仍搜 A）—— 它能否由「痕迹衰减 + 覆盖激活」的动力学自发涌现，且再现 Diamond 的延迟反转 （错法在短延迟反而最高，非皮亚杰原读的”越短越错”）。

机（冻结）

双物 A、B，痕迹强 a_A, a_B ∈ [0,1]。每拍动力学：

  • 呈现 X：a_X ← a_X + α(1−a_X)，α=0.15； 语义重叠扩散：a_Y ← a_Y + αρ(1−a_Y)/2，重叠 ρ ∈ {0, 0.5}。
  • 衰减（缺输入时）：a ← a − μ·a·(1 + ν(1−a))，ν=1（弱痕衰快于强痕，Ebbinghaus 式）； μ ∈ {0, 0.001, 0.005, 0.02, 0.1} 五档脚手架（μ=0 即”强恒常”对照臂）。

试次序列（经典藏找范式之抽象）： ① 锚定期：A 呈现 20 次（每拍一呈）；② 覆盖期：B 呈现 k 次（每呈间隔 5 拍，k ∈ {0, 8}，k=0 即无转移对照）； ③ 缺席期：Δ 拍无任何输入，Δ ∈ {0, 15, 30, 60, 120, 240, 480}； ④ 探针：搜索判决取 argmax(a_A, a_B) 叠 ε=0.02 各向同性选择噪声，判 B 即 A-not-B 错； ⑤ 重现期：A 复呈至 a_A ≥ θ=0.7，记 T_rec；自零痕冷启至 θ 记 T_cold。 节省分 S = 1 − T_rec/T_cold ∈ [0,1]（Ebbinghaus 节省法直译：行为已失而节省>0 即”潜知未死”）。

格：μ5 × Δ7 × ρ2 × k2 = 140 格，每格 2000 试次，籽 {11,22,33}（噪声流），全向量化。

判据（冻结，先册后读）

  1. 存活判：S(Δ_max=480, μ) > 0.5 → 判”概念存活于缺席”；S ≤ 0.2 → 判”灰飞”；其间如实报部分存活。
  2. 错置判：k=8 臂 P_err(Δ) 峰值 > 0.5 且 k=0 同格 P_err < 0.5 → A-not-B 错在机中成席。
  3. 反转判：k=8 且 ρ=0.5 臂中 P_err 对 Δ 先高后低（Δ≤30 均值 − Δ∈[120,480] 均值 > 0.1） → Diamond 延迟反转复现；方向相反则如实报反写。
  4. 潜知窗口：存在 Δ 窗使「探针判对率 ≈ 0.5（行为丢失）」且「S > 0.5（节省犹在）」 → 「忘了但还在」窗口成席——客体恒常的行为面与知识面解耦。
  5. 器自校（新尺先校）：μ 档闭式衰减骨架（纯乘性、ν=0）MC 均值对解析解 |Δa| ≤ 0.02 过了才判新数。
  6. 即算即落盘（园律 0927）：每格算完即 append out_v1/report_n01.jsonl； 哨兵词 N01-ABSENCE-DONE；四验收：140 格齐 · 每格 T_cold>0 · 哨词在录 · 无 0 字节壳。

诚实牌

  • 标量双痕迹机是 A-not-B 的最小动力学骨架，不是婴儿——本案只裁「衰减+覆盖激活能否产生文献签名」， 真语料（MACS 藏找对话序列）到库后另案对撞。
  • ν=1（弱痕衰快）是一枚可调脚手架而非自然律；主判读须并报 ν=0 臂（5 号自校即此臂之闭式）。
